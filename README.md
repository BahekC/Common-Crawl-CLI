# Common Crawl CLI

Консольное Python-приложение для учебного исследования архива Common Crawl.
Оно находит сохранённые URL через актуальный CDX-индекс, а по флагу
`--show-text` загружает только нужный диапазон WARC-файла и извлекает заголовок
и короткий фрагмент текста.

## Запуск

```powershell
python -m pip install -r requirements.txt
python common_crawl.py news --domain pstu.ru --limit 5
python common_crawl.py commoncrawl.org/get-started --show-text
python common_crawl.py --help
```

Аргументы:

- `keywords` — одно или несколько слов либо URL;
- `--domain` — ограничение доменом и его поддоменами;
- `--limit` — максимальное число строк, по умолчанию 10;
- `--show-text` — загрузить WARC-запись через HTTP `Range` и показать текст.
- `--crawls` — сколько последних обходов проверить, по умолчанию 3.

Используемый стек соответствует рекомендациям со слайда:

- `cdx-toolkit` объединяет месячные CDX-индексы и повторяет временно
  неудачные запросы с задержкой;
- `requests` выполняет точечные HTTP Range-запросы;
- `warcio` потоково разбирает полученную WARC-запись;
- `beautifulsoup4` извлекает заголовок и видимый HTML-текст;
- `pandas` формирует итоговую таблицу;
- `tqdm` показывает прогресс чтения WARC;
- `argparse` из стандартной библиотеки реализует CLI.

## Как устроен поиск

CDX Common Crawl — индекс URL, а не содержимого страниц. Поэтому без загрузки
WARC невозможно искать произвольную фразу в тексте или узнать HTML-заголовок.
Приложение следует этому ограничению:

- с `--domain` выбирает страницы домена и оставляет URL, содержащие **все**
  ключевые слова;
- без `--domain` отправляет каждое слово/URL как отдельный запрос к URL-индексу;
- без `--show-text` в колонке заголовка стоит `—`;
- с `--show-text` получает из CDX ограниченный пул страниц, загружает только
  байты `offset..offset+length-1` каждой записи и оставляет страницы, в тексте
  которых встречаются все ключевые слова. Полный WARC (обычно около гигабайта)
  не загружается.

Пример поиска упоминаний из задания:

```powershell
python common_crawl.py "Пермь" "Пермский Политех" --domain pstu.ru --show-text
python common_crawl.py "кафедра" "ИТАС" --domain pstu.ru --show-text
python common_crawl.py "МГУ" --domain msu.ru --show-text
python common_crawl.py "МФТИ" --domain mipt.ru --show-text
python common_crawl.py "Борис Пастернак" "Пермь" --domain culture.ru --show-text --crawls 5
python common_crawl.py teatr-teatr.com/performances/doktor-zhivago "Борис Пастернак" "Пермь" --show-text
```

В полнотекстовом режиме проверяется суммарно от 12 до 40 приоритетных URL
(в зависимости от `--limit`) из выбранных обходов. Несколько обходов позволяют
сравнивать даты и находить страницы, отсутствующие в последнем срезе. Это
безопасный интерактивный поиск, а не обход всего корпуса.

Если известна тематическая страница, её URL можно передать первым позиционным
аргументом без `--domain`; остальные аргументы будут искаться в её архивном
тексте. Это самый точный и быстрый способ проверить исследовательскую гипотезу.
